# KOL 返佣活动增量 ROI 分析

本项目复盘 K 交易所（虚构平台）为期 30 天的 KOL 双倍返佣活动。分析使用 Retail 客群作为同期自然增长参照，构建反事实基线，评估活动带来的真实增量、增量 ROI 与活动后留存效果。

> 数据均经过脱敏和虚构处理，与真实业务无关。

## 核心结论

- 活动期间 KOL 交易额较活动前增长 **36.98%**。
- 剥离 Retail 同期 **7.89%** 的自然增长后，活动真实增量为 **44.51M U**，占表面增长的 **78.66%**。
- 增量毛手续费为 **8,821.31 U**，增量返佣成本为 **7,556.40 U**，增量净收益为 **1,264.91 U**，增量 ROI 为 **16.74%**。
- 活动后 KOL 交易额仍较活动前高 **16.47%**，但人均交易额仅高 **0.67%**，留存主要来自参与人数，而非单个 KOL 交易强度的长期提升。
- 不建议直接复制当前统一高返佣模式；更适合采用 KOL 分层、阶梯激励，并以新增净手续费与增量 ROI 作为核心评价指标。

## 分析方法

1. 按活动前、活动中、活动后各 30 天汇总核心指标。
2. 以未参与活动的 Retail 客群估计同期自然增长。
3. 构建无活动情景下的 KOL 理论交易额，计算真实增量。
4. 拆解增量毛手续费、增量返佣成本、增量净收益与增量 ROI。
5. 从交易规模、参与人数和人均交易额三个角度评估活动后留存。
